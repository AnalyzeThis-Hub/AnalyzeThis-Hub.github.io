Privacy policy

Last updated: October 11, 2026

This policy covers “Analyze This Uploader”, a private software tool operated by the owner of the YouTube channel “Analyze This”. The tool is used only by its owner, to manage that one channel. It has no other users.

YouTube API Services

The tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google’s handling of data is described in the Google Privacy Policy.

What the tool accesses

With the owner’s permission, the tool uses YouTube API Services to:

  • upload videos, titles, descriptions, thumbnails and captions to the owner’s own YouTube channel;
  • read basic information and analytics (such as views and watch time) about the owner’s own channel and videos.

The tool does not access the data of any other YouTube user or channel.

How data is used and stored

  • Data from YouTube is used only to operate and improve the owner’s channel.
  • The tool stores login tokens, the IDs and titles of videos it uploaded, and analytics numbers for the owner’s own channel. They are kept on servers controlled by the owner and are not accessible to other people.
  • Analytics numbers read from YouTube are kept no longer than 30 days before they are refreshed or deleted.
  • We do not sell, rent or share this data with third parties, and we do not use it for advertising.

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data deletion

  • Stored login tokens are deleted as soon as access is revoked, and on request at any time.
  • Other stored data from YouTube is deleted on request, and when it is no longer needed.
  • To request deletion, contact us through the “Analyze This” YouTube channel.

Revoking access

Access can be removed at any time on the Google Account permissions page: myaccount.google.com/permissions. Select “Analyze This Uploader” and choose to remove access. After access is removed, the tool can no longer reach the channel.

Visitors to this website

This website is a static page. It does not use cookies, analytics or forms, and it does not collect personal information.

Contact

For questions about this policy, contact us through the “Analyze This” YouTube channel.
